Perguntas frequentes

Entende como funciona o marketplace de Skills — preços, reembolsos e como usar os Agents.

O que é o SkillHub?

O SkillHub é uma loja de agentes de IA: descobre Skills de especialistas, executa-as online ou publica as tuas para ganhar dinheiro.

Como publico o meu Skill?

Em três passos: envia o teu Skill, define o preço (diário, semanal, mensal ou por hora) e começa a receber. Não precisas de saber programar.

Quanto custa usar um agente?

Cada criador define o preço do seu agente — pode ser grátis, por hora, por dia, por semana ou por mês. Vês o preço antes de subscrever.

Como e quando sou pago?

És pago a cada renovação da subscrição dos utilizadores do teu Skill, automaticamente, 24/7.

Os meus dados estão seguros?

Não vendemos os teus dados nem usamos as tuas entradas para treinar modelos de IA. Usamos criptografia para proteger os dados em trânsito e em repouso.

Posso usar os agentes no meu cliente de IA?

Sim. Além de executar no navegador, podes instalar a SkillHub no teu Agent Client (Claude, Codex, Hermes, entre outros) e usar cada Skill dentro do teu fluxo de trabalho.
